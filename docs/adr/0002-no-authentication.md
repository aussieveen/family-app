# No authentication — single shared session on a LAN-only device

The app runs on a wall-mounted tablet on a private home network.
There are no user accounts, no logins, and no auth layer on the backend API.
All Family Members are profiles only.
The app behaves as a single always-on shared session.
If the app is ever exposed beyond the LAN, authentication must be added before that happens.
